EN - Hey everyone!

I decided to write my own Baritone completely from scratch for Minecraft 26.2 Fabric.

At the moment, the only available feature is a single command: `$mine <ore_name>`. For example, `$mine diamond_ore` will make the bot automatically start mining the specified ore and build paths to reach it.

That's pretty much all for now, but I'm planning to gradually add more features, fix bugs, clean up and optimize the code. Hopefully, over time, this will turn into a fully-fledged, clean and fun little Baritone of its own.

I'm developing it completely by myself and from scratch, so I hope to release updates fairly often.

Well, this is just the beginning. 👀

# Baritone Reborn

Чистый каркас Fabric-мода для Minecraft 26.2.

## Команды

- `$info` — локальная информация о моде; команда не отправляется на сервер.
- `$mine minecraft:diamond_ore` — выбирает один зарегистрированный блок и включает контроллер добычи.
- `$mine stop` — выключает контроллер добычи.

## Структура

- `baritone.BaritoneMod` — общий entrypoint и логгер.
- `baritone.client.BaritoneClient` — клиентские команды и lifecycle.
- `baritone.mining` — состояние добычи и модель целей руды.
- `baritone.movement` — профиль ограничений плавного человеческого движения.

Контроллер сканирует загруженные чанки, выбирает ближайшую цель, строит ограниченный A* маршрут, запрещает узлы с лавой, прокапывает твёрдые блоки по пути, выбирает лучшую кирку из хотбара и отправляет обычные client-side команды ломания блоков. Цель рисуется 3D-боксом, маршрут — линией.

## Проверка

Проект собирается командой `gradle build` на Java 26 и Minecraft 26.2. Клиентская задача `runClient` также проходит и регистрирует обе команды.
